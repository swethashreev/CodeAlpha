# Task 1 - Exploratory Data Analysis (EDA)

## 📊 Student Performance Dataset

EDA on student performance data using Python, Pandas, Seaborn and Matplotlib.

### Tools Used
- Python
- Pandas
- Numpy
- Matplotlib
- Seaborn
- Scipy

### Key Findings
- Higher study time → Higher final grades
- Higher alcohol use → Lower grades
- Internet access → Slight grade improvement
- Parental education positively impacts grades
- G1, G2, G3 are highly correlated
