# Objective
Transform raw data into visual formats like charts, graphs, and dashboards to reveal insights and support data-driven decision-making.

# Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

# Dataset
Used the built-in **Seaborn `tips` dataset**, which contains information about restaurant bills, tips, customer demographics, and dining details.

# Visualizations Created
- Histogram: Distribution of total bill amounts
- Bar Chart: Average tip by day of the week
- Scatter Plot: Relationship between total bill and tip, by gender
- Box Plot: Total bill distribution by day and time
- Heatmap: Correlation between numeric variables
- Pie Chart: Smoker vs Non-smoker proportion
- Combined Dashboard: Multiple visuals in a single view

# Key Insights
- Tips generally increase with the total bill amount.
- Dinner bills tend to be higher than lunch bills.
- Most customers are non-smokers.
- Tipping behavior varies slightly by day and gender.

# Outcome
Built a clear, visually appealing dashboard that effectively communicates patterns in restaurant billing and tipping behavior, useful for business decision-making.
